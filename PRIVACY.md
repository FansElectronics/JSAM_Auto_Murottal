# Kebijakan Privasi JSAM Auto Murottal

Terakhir diperbarui: 29 Oktober 2026

JSAM Auto Murottal ("kami") menghormati privasi Anda. Kebijakan Privasi ini menjelaskan bagaimana aplikasi kami menangani data pengguna.

1. Informasi yang Kami Kumpulkan
Aplikasi JSAM Auto Murottal dirancang untuk mengontrol dan mengonfigurasi perangkat pemutar audio/murottal otomatis melalui koneksi nirkabel (WiFi / Jaringan Lokal). Kami TIDAK mengumpulkan, menyimpan, atau membagikan data identitas pribadi (seperti nama, email, lokasi GPS presisi, kontak, atau nomor telepon).

2. Izin Perangkat yang Digunakan
- Akses Jaringan / WiFi (INTERNET, ACCESS_WIFI_STATE, CHANGE_WIFI_STATE): Digunakan semata-mata untuk berkomunikasi langsung dengan perangkat keras kontroler melalui jaringan lokal.
- Akses Penyimpanan / Media: Digunakan hanya untuk membaca file audio murottal yang dipilih oleh pengguna di perangkat lokal jika diperlukan.

3. Layanan Pihak Ketiga
Aplikasi ini tidak menyertakan SDK pelacakan (tracking), analitik pihak ketiga yang invasif, atau jaringan iklan pihak ketiga.

4. Keamanan Data
Karena kami tidak mengumpulkan data pengguna ke server cloud eksternal, tidak ada data pribadi pengguna yang disimpan atau ditransmisikan di luar jaringan lokal perangkat Anda.
