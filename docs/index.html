Kebijakan Privasi JSAM Auto Murottal

Pembaruan Terakhir: November 2026

Aplikasi JSAM Auto Murottal dikembangkan oleh Fans Electronics sebagai aplikasi utilitas kontrol perangkat keras audio/murottal. Kebijakan Privasi ini menjelaskan komitmen kami dalam menjaga privasi data Anda saat menggunakan aplikasi.

1. Pengumpulan dan Penggunaan Data Pengguna

Aplikasi ini beroperasi murni sebagai pengendali perangkat lokal. Kami tidak mengumpulkan, melacak, merekam, membagikan, atau menjual data identitas pribadi pengguna (seperti nama, alamat email, nomor telepon, kontak, maupun data finansial).

2. Akses Lokasi & Koordinat

Aplikasi tidak menggunakan sensor GPS perangkat maupun meminta izin lokasi sistem Android (ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION). Nilai lintang (latitude) dan bujur (longitude) pada halaman pengaturan murni merupakan nilai numerik yang dimasukkan secara manual oleh pengguna (atau dipilih dari referensi kota) untuk dikirimkan langsung ke modul jadwal perangkat keras.

3. Izin Perangkat (Device Permissions)

  • Akses Jaringan & WiFi: Digunakan semata-mata untuk menghubungkan aplikasi ke jaringan lokal perangkat keras kontroler guna mengirimkan perintah dan parameter konfigurasi.
  • Penyimpanan Lokal: Digunakan secara lokal untuk memilih dan membaca file audio atau jadwal yang dipilih langsung oleh pengguna.

4. Pemrosesan Data dan Pihak Ketiga

Seluruh konfigurasi yang Anda kirimkan diproses secara langsung antara ponsel Anda dan perangkat modul kontroler di jaringan lokal Anda. Aplikasi ini tidak menggunakan SDK pelacak pihak ketiga, layanan analitik yang mengumpulkan profil pengguna, maupun jaringan periklanan.
