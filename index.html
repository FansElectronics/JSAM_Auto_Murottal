Kebijakan Privasi JSAM Auto Murottal

Terakhir diperbarui: 29 Oktober 2026

JSAM Auto Murottal ("kami") menghormati privasi Anda. Kebijakan Privasi ini menjelaskan bagaimana aplikasi kami menangani informasi pengguna saat menggunakan aplikasi.

1. Pengumpulan dan Penggunaan Data

Aplikasi JSAM Auto Murottal dirancang untuk mengonfigurasi dan mengontrol perangkat keras audio/murottal otomatis melalui koneksi nirkabel (WiFi / Jaringan Lokal). Kami tidak mengumpulkan, menyimpan, melacak, atau membagikan data identitas pribadi pengguna (seperti nama, email, nomor telepon, atau data finansial).

2. Izin Perangkat (Permissions) & Akses Lokasi

  • Akses Lokasi (ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION): Aplikasi mengakses data lokasi perangkat pengguna dengan tujuan:
    • Mengambil koordinat (lintang dan bujur) saat ini untuk konfigurasi otomatis pengaturan lokasi pengguna pada perangkat.
    • Memenuhi persyaratan sistem operasi Android saat memindai jaringan WiFi lokal perangkat kontroler.
    Penting: Data lokasi ini hanya diproses secara lokal di perangkat Anda untuk mengisi parameter pengaturan dan tidak pernah dikirim, disimpan, atau dibagikan ke server pihak ketiga/cloud eksternal kami.
  • Akses Jaringan & WiFi: Digunakan untuk mengirimkan parameter konfigurasi langsung ke perangkat keras kontroler melalui jaringan lokal.
  • Penyimpanan / Media: Digunakan untuk memilih dan memutar file audio murottal dari penyimpanan lokal perangkat.

3. Layanan Pihak Ketiga

Aplikasi ini tidak menggunakan SDK pelacak pihak ketiga, analitik yang melacak identitas, maupun jaringan iklan pihak ketiga.

4. Keamanan Informasi

Karena seluruh komunikasi kontrol perangkat dilakukan di jaringan lokal tanpa mengirimkan data ke server cloud eksternal, data konfigurasi Anda tetap berada dalam kendali perangkat Anda sendiri.
